# 결정 원장 (D-*) + 논의록 결정 색인

청첩장 결정의 단일 진입점입니다. 2부 구조입니다.

1. **D-\*** = 외부·크로스커팅 결정(아래 표). 행의 결정 내용은 불변입니다. 뒤집힘은 새 번호 행으로 대체하고 옛 행 상태에 "폐기 — D{n}으로 대체"를 적습니다.
2. **논의록 결정 색인** = AI 논의에서 난 설계 결정은 각 논의록의 결정 표가 정본이고, 여기는 그 표의 네임스페이스 색인만 둡니다(복제 없음). 인용 규칙: 홈 네임스페이스 밖에서는 접두 필수("부트스트랩 결정 1"). 규칙 정본은 `docs/dashboard/README.md` §논의입니다.

상태: **확정**(유효한 규범) · **잠정**(방향 합의, 확정 전) · **종결**(소임을 다해 더 이상 규범이 아님) · **폐기**(대체됨)
